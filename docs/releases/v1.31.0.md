# Version 1.31.0 — Mock exams as long as the real one, scored against a higher target

The WatchGuard Network Security Essentials exam is 70 questions with a 75%
passing score (Study Guide, Fireware v12.9.2, pp. 336-338). The Local Firebox
mock was 50 questions, and its results only said whether an attempt reached
75%. An attempt at exactly 75% read as a pass with no warning that one harder
set of questions on the day would fail it.

## A Local Firebox mock is 70 questions

- A mock drawn from the whole Local Firebox track now has **70 questions**,
  split by the published category weights as **7/7/10/18/18/10** (was
  5/5/7/13/13/7 at 50). The split is exact on every seed, and an authored
  question still appears at most once.
- **Timed mode** keeps its pace of one minute per question, so a full timed
  mock runs 70 minutes. It is still labelled a practice pace, not the official
  limit.
- The Study mode option reads **Mock Exam · up to 70 questions** on the Local
  Firebox track.
- Nothing else changes length. Network+, Cloud and All tracks stay at 50, and
  so does a Local Firebox mock filtered so it cannot cover every category (one
  topic, one format, or fresh scenarios only). CompTIA gives Network+ only a
  maximum of 90 questions, not a fixed number, so there is no real length to
  match.

## 75% to pass, 85% to aim for

The app already had an 85% practice target (Training Analytics, the exam
planner). The results screen and Exam readiness now use it alongside the pass
mark, in three bands:

| Score | Results screen says | Border |
| --- | --- | --- |
| 85% or more | "That clears the 75% the real exam needs and the 85% target." | green |
| 75–84% | "That would pass the real exam, which needs 75%, but is 5 points short of the 85% target that leaves room for a harder set on the day." | amber (new) |
| Below 75% | "That is 25 points short of the 75% the real exam needs, and 35 short of the 85% target." | red |

Exam readiness on Progress & Admin uses the same bands. Each category bar
keeps its grey line at 75%, gains a green line at 85%, and turns green only
once it reaches 85%; it used to turn green at 75%. A note under the table says
what the two lines mean.

The 85% comes from one constant, `PLAN_TARGET` in `src/engine/examPlan.ts`.
Training Analytics used to hard-code it twice and now reads it from there too.
Network+ results still show no percentage pass mark or target, because CompTIA
reports a scaled score.

## Impact

No migration, storage change or deploy-script change. A mock already in
progress keeps its saved length; the next one started on the Local Firebox
track is 70 questions. `scripts/check-track-chunks.mjs` now expects "Question
1 of 70" on the Local Firebox track. Delivered by pull request; it does not
deploy itself until merged to `main`.
