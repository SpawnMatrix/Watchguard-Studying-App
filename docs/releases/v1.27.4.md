# Version 1.27.4 — motion 14 and lucide-react 1

The second of four dependency-upgrade releases: the libraries the interface
renders with.

| Package | From | To |
| --- | --- | --- |
| `motion` | 12.42.2 | **14.0.0** |
| `lucide-react` | 0.546.0 | **1.52.0** |
| `react`, `react-dom` | 19.2.7 | 19.2.8 (latest 19.2 patch, now pinned `~19.2.8`) |

## React stays on 19.2, on purpose

React 19.3 was the obvious in-range update to take along. Measured, it grew
`react-dom` by about 92 kB before minification. With it, the entry chunk went
from 263.0 to 296.9 kB (82.6 → 92.5 kB gzip), undoing a quarter of what 1.27.1
saved, and the portal uses nothing 19.3 adds.

The range is now `~19.2.8`: patch releases arrive with `npm update`, and a
minor needs a deliberate change and a measurement. When something in 19.3 is
worth 9 kB gzip to every visitor, take it then.

## What the majors cost and changed

- **lucide-react 1.x** adds about 1.2 kB gzip to the entry. Every icon the
  portal imports still exists under the same name (`tsc` clean). They render
  with the same `lucide lucide-<name>` classes the diagram-marker tests rely
  on.
- **motion 14** stays in its own on-demand chunk, 126.6 kB, as split out in
  1.27.1. `MotionGlobalConfig.skipAnimations`, which `components/motion.ts`
  uses for reduced motion, is unchanged.

Entry chunk after this release: **267.4 kB, 83.8 kB gzip**.
