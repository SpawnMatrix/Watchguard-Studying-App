# Version 1.9.0 — Local Firebox bank matched to the WatchGuard NSE exam

WatchGuard publishes the shape of the Network Security Essentials for Locally-Managed Fireboxes exam in its Study Guide (Fireware v12.9.2, Assessment Objectives, pp. 336-338): six categories with approximate weights, 70 questions, and a 75% passing score. This release measures the Local Firebox question bank against that outline and closes the gaps, as 1.5.0 did for Network+.

| Category | Exam | Before | Now |
| --- | --- | --- | --- |
| Network and Network Security Basics | 10% | **0% (1 question)** | 8% (37) |
| Administration and Setup | 10% | 15% | 13% |
| Monitoring, Logging, and Reporting | 15% | 13% | 14% |
| Networking and NAT | 25% | 22% | 23% |
| Policies, Proxies, and Security Services | 25% | 27% | 23% |
| Authentication and VPNs | 15% | 22% | 19% |

The biggest finding: the exam's Basics category (IPv4 addressing, subnetting and routing, NAT, TCP/IP/HTTP headers, MAC addresses, ports and protocols) had a single question on the Local Firebox track.

## New content: 69 Local Firebox questions

- **Network and Network Security Basics (36):** subnet and broadcast arithmetic in Firebox interface terms, private ranges and dynamic NAT, longest prefix match and the default route, gateway-outside-subnet faults, MAC addresses and ARP, what changes at each hop, TCP connection identity and the handshake, TTL, UDP, ICMP, and the ports a Firebox administrator meets (DHCP, SMTP, NTP, SNMP, syslog, IKE), plus HTTP Host headers and status codes.
- **Monitoring, Logging, and Reporting (16):** the five log message types, alarm messages, diagnostic log levels, logging traffic sent from the Firebox, report-only logging, primary and backup log servers, sending logs to several destinations, Firebox System Manager tabs (Bandwidth Meter, Service Watch, Subscription Services, NIC link colours), support files, Web UI System Status pages, Unhandled External Packet, and Policy Map and Executive Summary.
- **Networking and NAT (17):** custom interfaces and aliases, routing modes and Bridge Mode limits, network bridges, why VLANs rather than secondary networks separate traffic, tagging ports for end devices, VLAN ID range, Firebox DNS server order and what depends on it, how SD-WAN actions treat new connections and replies, the sticky connections table, intra-interface inspection, the default scope and source-port behaviour of dynamic NAT, Server Load Balancing, and static NAT source addresses.

Every fact was checked against the Study Guide's own sections. The new questions were measured for the answer-length tell before release: the correct option is the longest in 22% (Basics) and 17% (Monitoring and Networking) of questions where length is noticeable.

## Mock exams and results

- **A Local Firebox mock exam now draws to the NSE blueprint:** 5 Basics, 5 Administration, 7 Monitoring, 13 Networking and NAT, 13 Policies and Security Services, and 7 Authentication and VPNs, shuffled together. Single-topic and generated-only pools keep the uniform draw.
- **The results screen scores a Local Firebox mock by category and compares it with the published 75% pass mark,** for example "68% overall. The real exam needs 75%, so this attempt is 7 points short." Network+ results still show domains without a percentage pass mark, because CompTIA reports a scaled score.

## Keeping it that way

`src/data/nseBlueprint.ts` classifies every Local Firebox question. A question's topic sets its default category, and 86 questions are overridden by id where the topic misleads. `nseBlueprint.test.ts` fails if a question is unclassified, if a category drifts more than five points from its weight, or if a category has fewer than 30 questions.

No database migration or deployment configuration change is required. New question ids (1800-1903) leave existing progress untouched.
