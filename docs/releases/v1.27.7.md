# Version 1.27.7 — Missing build assets return 404

Requests for missing files under /assets now return a plain-text, non-cacheable
404 instead of the HTML shell. Existing assets retain immutable caching, and
ordinary client-side deep links still serve the shell. Development is unchanged.

## Verification

- npm run lint; npx vitest run: 59 files, 490 tests passed; npm run build passed.
- New HTTP server tests cover missing JS, nested CSS and fonts with GET/HEAD,
  existing immutable assets, and the shell at root and deep links.
- NODE_ENV=production with a scratch DATA_DIR: missing JS/CSS returned 404;
  root, a deep link and health returned 200.
- No local Docker verification; the PR container job runs the production image.
