# Version 1.29.1 — Accessibility checks cover the states learners open

The production Playwright/axe sweep expands from 24 to 48 screens, in dark
and light themes. It adds the profile dialog, sign-in, recovery and assisted
recovery dialogs; expanded Q&A notes on all three tracks; a completed lab;
public Ideas posts in open, planned and shipped states with anonymous/named
authors and replies; and an exam date entered through the planner on all tracks.

The completed-lab fixture is derived from the real steps. Ideas responses are
browser fixtures: this test creates no account or post on the target server.
Each added check waits for the intended state to render, so a missing state
fails the test instead of silently scanning an empty screen.

## Verification

- Expanded sweep against NODE_ENV=production with scratch DATA_DIR: all 48
  screens passed WCAG 2.1 A/AA with zero axe violations and an empty allowlist.
  No additional contrast fix was needed in these states.
- npm run lint, npx vitest run (60 files, 499 tests), npm run build and the release gate passed. CI repeats the expanded sweep and builds the container.
- This covers rendered states with axe, not a full screen-reader audit or
  every possible dialog/error state. Fixture board checks validate presentation;
  existing server tests cover real suggestion authorization and persistence.
