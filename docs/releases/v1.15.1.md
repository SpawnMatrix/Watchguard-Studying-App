# Version 1.15.1 — Readable topology diagrams

Network topology diagrams (the Break-Fix lab, topology quiz questions, and Topology Studio) were rendering their node and link text far smaller than intended. The diagrams scale an SVG viewBox down to fit a capped display height, and the base font sizes were tuned for the un-scaled size — at the scale most diagrams actually render, node labels landed around 9px and detail/zone text around 6-7px on screen.

- Node labels, zone tags, link labels, and the legend all render at a larger base size, so they stay legible after the same proportional shrink.
- The SVG's display height ceiling raised from 520px to 640px, so wide, tall diagrams (like the Break-Fix lab's branch-office network) clamp less aggressively before scaling.
- Node card borders and connection lines are drawn slightly thicker for contrast against the dark background.
- Detail-line wrapping and vertical spacing inside each node card were adjusted to match the larger text without overflowing the card.

This is a presentation-only change to `NetworkTopology.tsx` and its styles — no diagram data, question content, or grading logic changed. No SQLite migration, volume replacement, or topology data-contract change is required.
