# Version 1.28.2 — Build tools stay out of the production image

Vite, plugin-react and the Tailwind Vite plugin move to devDependencies only.
The two plugins must move too: their peer dependencies otherwise reinstall Vite
in an omit-dev installation. Versions are unchanged. The builder still installs
all dependencies; the runtime stage installs only production dependencies.

The server imports Vite dynamically only when NODE_ENV is not production.
Production defaults and image entrypoint stay unchanged. CI now also asserts
that Vite and both plugins cannot be resolved inside the production image,
before exercising smoke flows and persisted accounts across replacement.

## Verification

  release gate passed. npm audit reports zero vulnerabilities.
- Source inspection confirms the only server import of Vite is guarded by
