# 1.16.0 — A refreshed study workspace

The study portal has a new visual layout built on the existing Vite, React and Tailwind stack.

- A compact header keeps the learning track visible and groups account access, display-name editing, save status and session details in an accessible menu. The menu closes with Escape or when focus leaves it.
- Study Home pairs the saved-quiz action with a network illustration, four study shortcuts, a unified progress strip, topic accuracy and a seven-day activity chart. The chart uses recorded answer counts; the accuracy comparison now reads from previous answers to latest answers.
- Quieter borders, clearer typography and consistent buttons connect Home, quizzes, topology, labs and settings. Phone navigation uses one horizontally scrollable row instead of two rows of large tiles.
- Both themes are supported. The decorative packet animation runs on hover or keyboard focus and stops for reduced-motion preferences; React section transitions now also respect that preference.
- Topology feedback adds check/cross markers, and submitted quiz answers remain readable in light mode. The latest topology text-size fix is retained. The topology v1 contract is unchanged.
- Personal tutor and Administrator controls are separate views. Their forms stay mounted when switching; the administrator form stacks on phones. Display-name editing can always be cancelled.

No question-bank, grading, synchronization, authorization, API or database-schema changes are included. Existing learner progress and saved sessions remain compatible. See [the UI review notes](../modern-workspace.md).
