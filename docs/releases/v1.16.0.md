# Version 1.16.0 — Measure exam coverage before claiming readiness

Broadly balanced topic counts hid empty objectives and definition-only practice. The new exam coverage report maps each question and generated concept to a primary exam objective, separates recall from applied work, and measures the actual mock sampler over 2,000 seeds per track before and after this change.

- Adds 28 original scenarios: five Local Firebox, seven Network+, and sixteen Cloud. These introduce Local content actions/domain routing, Network+ appliance selection and management access, and Cloud networking, inspection, authentication-domain and VPN decisions.
- Names the remaining gaps. Cloud grows from 33 to 49 concepts versus Local's 490, and still has 13 empty rows in the historical Cloud checklist. Its mock repeats the lone management template five times after twin suppression; this is not a complete cloud-managed exam preparation bank.
- Distinguishes the supplied March 2023 Local guide, the retrieved CompTIA objectives document v6.0, and the provisional June 2022 Cloud checklist. The current official Cloud criteria could not be independently retrieved, so the report does not invent a current blueprint.
- Measures new-question answer-length bias independently: 7/28 (25%) strictly longest, zero ties, and zero answers more than four characters longer than every distractor. Protected content and engine guards are unchanged.

No migration or sampler behavior change. Existing question IDs, saved progress, and lab behavior are retained. This branch is delivered through a pull request and does not deploy itself.
