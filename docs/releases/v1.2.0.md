# Version 1.2.0 — topology practice and study tracks

This release brings together the merged visual and topology-content work, plus the follow-up controls for practicing it.

- Study Home shows observed topic accuracy, recent results, recorded activity, and a saved-quiz resume action.
- The global Network+, locally-managed Firebox, and cloud-managed Firebox selector filters Q&A and flashcards. Saved quizzes remain resumable. Explicit new exams and mode changes adopt the selected track without erasing history.
- Practice settings can focus on network diagrams, traffic logs, policy ordering, or multiple-choice questions. The format filter combines with the existing topic, track, and authored/generated pool filters. Old saved sessions default to all formats.
- A dedicated Topology Lab offers a track-filtered scenario catalog, diagram previews, practice for a selected diagram, guided practice, and topology mock exams using the existing quiz engine.
- SVG topology questions use stable node/edge IDs for hotspots. Fit-to-width and readable-size controls make wider networks easier to inspect. Packet animation can be paused and respects reduced-motion preferences. Expand network details for complete device and connection text.
- Stacked-device link labels sit in the gap between cards; long horizontal labels move above the cards rather than disappearing behind them.
- The footer credits Julien Dumitrescu and reads the version from package.json, as does `/api/version`. Build commit metadata continues to identify the deployed image.
- Last built shows the immutable image build time in the viewer's timezone. Vite emits the same timestamp into the page and build-info.json; the production API reads that artifact. A new image has its own timestamp, while a page refresh or container restart does not change it. Development previews are explicitly labeled.
- The PR release check requires a version greater than the target branch, matching package/lockfile versions, and a release-notes file. Run `npm run check:release` locally after fetching origin/main. Patch releases suit fixes; minor releases suit added study features.

No SQLite migration, volume replacement, deployment-script update, or topology v1 contract change is required. Keep the persistent data volume when deploying. This branch is delivered by pull request; it does not merge or deploy itself.
