# Version 1.6.0 — Network+ mock exams follow the exam blueprint

Version 1.5.0 balanced the Network+ question bank against the N10-009 domain weightings. A balanced bank still produced unbalanced mocks, because each mock drew its 50 questions uniformly. Measured over 20,000 mocks, Network Security (7 questions on the real exam's proportions) drew anywhere from 1 to 16, and four or fewer in one mock in ten. Troubleshooting came up short just as often.

## What changed

- **Every Network+ mock now has the exam's shape:** 12 Networking Concepts, 10 Network Implementation, 9 Network Operations, 7 Network Security and 12 Network Troubleshooting questions, shuffled together so domains are interleaved.
- **A finished Network+ mock shows a score for each domain** next to that domain's exam weight, and names the weakest one. A single overall percentage can hide a weak domain that the real exam will find.
- **Other mocks are unchanged.** Local Firebox, WatchGuard Cloud, All tracks, a single topic, and filters that leave a domain empty (such as generated-only or diagrams-only) still draw uniformly. There is no blueprint to honour there, and forcing one would distort it.

Mocks remain reproducible from their seed, authored questions still never repeat within one, and a saved mock in progress keeps its original queue.

No database migration or deployment configuration change is required.
