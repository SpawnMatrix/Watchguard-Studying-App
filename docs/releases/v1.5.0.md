# Version 1.5.0 — Network+ bank matched to the N10-009 blueprint

The Network+ question bank now practises each exam domain in roughly the proportion the real exam asks about it. Measured by classifying every Network+ question against the published N10-009 objectives, the bank had drifted a long way:

| Domain | Exam | Before | Now |
| --- | --- | --- | --- |
| 1.0 Networking Concepts | 23% | 29% | 24% |
| 2.0 Network Implementation | 20% | 18% | 20% |
| 3.0 Network Operations | 19% | 29% | 18% |
| 4.0 Network Security | 14% | 6% | 14% |
| 5.0 Network Troubleshooting | 24% | 17% | 24% |

A learner scoring well before this release had largely been practising Operations, and had seen seven Security questions in total.

## New content — 65 Network+ questions

- **Network Security (new topic, 18):** TACACS+ versus RADIUS, VLAN hopping, evil twins, ARP poisoning, MAC flooding, port security, screened subnets, honeypots, device hardening, MFA factor categories, DDoS, IoT segmentation, tailgating, self-signed certificates, DNS cache poisoning, data at rest, and role-based access control.
- **Troubleshooting (23):** fiber type mismatches, crosstalk, err-disabled and administratively down ports, root bridge elections, wrong VLANs, DHCP exhaustion, wrong subnet masks, implicit deny, jitter, WAN bottlenecks, channel width, roaming gaps, attenuation, and the tools and commands the objectives name (toner, visual fault locator, dig, netstat, ipconfig, LLDP, taps, Nmap, show mac-address-table).
- **Routing and Switching & Wireless (15):** longest prefix match, administrative distance, FHRP, BGP, PAT, native and voice VLANs, jumbo frames, SVIs, Wi-Fi 6E security, band steering, antennas, captive portals, rack airflow, and UPS versus PDU.
- **Network Architecture (new topic, 9):** cloud service models, security groups, direct connections, elasticity, LC connectors, DAC cables, spine and leaf, SDN, and zero trust. None of these were covered before.

Every new question was checked for the option-length tell before release: the correct answer is the longest option in 19% of measured questions, with its length rank spread evenly across all four positions.

Both new topics have "Explain like I'm an L1" guides and lab recommendations.

## Keeping it that way

`src/data/networkPlusBlueprint.ts` records the domain of every Network+ question, and `networkPlusBlueprint.test.ts` fails if a new Network+ question is left unclassified or if any domain drifts more than three points from its exam weighting.

No database migration or deployment configuration change is required. Question ids are new (1700–1778), so existing progress, history and weakness decks are unaffected.
