# Version 1.15.3 — Remove unused dashboard and lab-walkthrough files

Seven source files that nothing in the app, server, scripts or tests imported have been deleted. A repo-wide search (static imports, `lazy()`/dynamic `import()` sites, `import.meta.glob`/`require`, and tests that read component source from disk) found no references outside the files themselves.

- `src/components/dashboard/GlobalDashboard.tsx`, plus `RadialProgress.tsx` and `ActivityHeatmap.tsx`, which only it used. The live dashboard is `PerformanceDashboard.tsx`, which imports its panels from `dashboard/` by file path.
- `src/store/useStudyStore.ts`, the zustand store those three files read. Nothing else imported it.
- `src/components/dashboard/index.ts`, a barrel file nothing imported.
- `src/components/LabWalkthrough/LabCatalog.tsx` and `ActiveLabWalkthrough.tsx`, an old extraction. `src/components/LabWalkthrough.tsx` remains the component the app lazy-loads.

The `zustand` dependency is now unused but is left in `package.json` to keep this change to deletions only.

No migration, no data-contract or deploy-script change, and no change to what learners see. The branch is delivered by pull request and does not deploy itself.
