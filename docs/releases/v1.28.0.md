# Version 1.28.0 — Your daily flashcards on Home

Study Home lazily loads the flashcard count after painting. Its button opens
Flashcards and uses the same track filter, mastered exclusions, review schedule
and ten-new-cards daily allowance as the studio. It refreshes on study changes,
track changes, window focus and each minute (including across midnight).
A failed download leaves the ordinary Review flashcards link usable.
No new storage key or server data is introduced.
