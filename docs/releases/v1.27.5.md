# Version 1.27.5 — Vite 8 and Vitest 5

The third of four dependency-upgrade releases: the build and test toolchain.

| Package | From | To |
| --- | --- | --- |
| `vite` | 6.4.3 | **8.3.2** |
| `@vitejs/plugin-react` | 5.2.0 | **6.1.2** |
| `vitest`, `@vitest/coverage-v8` | 4.1.11 | **5.0.3** |
| `esbuild` (server bundle) | 0.25.12 | **0.28.2** |
| `@tailwindcss/vite`, `tailwindcss` | 4.1.x | 4.3.3 |
| `tsx`, `autoprefixer` | | latest patch / minor |

## What changed

- **Vite 8 bundles with Rolldown instead of Rollup.** Production builds now
  take about 0.5 s instead of 2.4 s, and the output is smaller:

  | | 1.27.4 | 1.27.5 |
  | --- | --- | --- |
  | Entry chunk | 267.4 kB / 83.8 kB gzip | **245.3 kB / 78.2 kB gzip** |
  | First-load JS, entry plus modulepreload | 83.8 kB gzip | **80.0 kB gzip** |
  | `motion` (on demand) | 126.6 kB | 122.2 kB |

  Rolldown splits lucide's shared `createLucideIcon` helper into its own small
  chunk and modulepreloads it, which is why the first-load figure counts both
  files.
- **`vite.config.ts` is ready for the native config loader.** Vite 8 warned
  that three things in the config would break when the native loader becomes
  the default: `__dirname`, a JSON import without import attributes, and an
  extensionless import. They now use `import.meta.dirname`,
  `with {type: 'json'}` and `./src/releaseInfo.ts`. `vitest.config.ts` uses
  `import.meta.dirname` too. The warning is gone, and `build-info.json` still
  carries the version.
- **Vite is still listed in both `dependencies` and `devDependencies`.** The
  first install attempt failed on exactly that duplication: the stale
  `dependencies` entries for Vite 6 and plugin-react 5 conflicted with the new
  dev ones. Both are now updated together. Moving Vite to dev-only would shrink
  the production image, because the server imports it only outside production.
  But that changes what the image installs, so it deserves its own change.
- **No code changes were needed for Vitest 5.**

## Verification

- `npx tsc --noEmit` clean. `npx vitest run` on Vitest 5: 58 files, 483 tests,
  green.
- `npm run build` (Vite 8 client + esbuild 0.28 server) clean.
- **Dev mode:** `tsx server.ts` started with Vite 8 middleware. It served the
  shell with the `/@vite/client` and `/src/main.tsx` scripts, transformed
  `main.tsx` (200, `text/javascript`) and served `index.css`.
- **Production build:** `scripts/smoke.mjs` passed. The accessibility sweep
  loaded every section's lazy chunk through the SPA: 24 screens, no
  violations.
- **Alpine image:** the lockfile records the `linux-x64-musl` native bindings
  for Rolldown, Tailwind's oxide and Lightning CSS, which the `node:22-alpine`
  image needs. CI's container job builds and smoke-tests the real image.
