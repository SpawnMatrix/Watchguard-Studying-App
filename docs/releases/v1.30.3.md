# Version 1.30.3 — More room for studying on phones

## What changed

- **Section navigation on phones is one scrolling row.** Below 800px wide, the
  ten section tiles stacked into three or four rows. At 390px that was 261px of
  tiles before any content showed; the row is now 78px, and section content
  starts 183px higher. The open section is scrolled into the row's view by
  setting the row's own scroll position, so moving between sections never
  scrolls the page.
- **No "0%" before the first answer.** Progress showed 0% quiz accuracy for a
  learner with no answers, while Study Home showed "—". Both now show "—".
- **The log viewer is readable in light mode, and CI stops failing at random.**
  The Traffic Monitor box stays dark in both themes, but light mode swapped its
  green and grey text for shades meant for white backgrounds (3.2:1 and 2.32:1).
  axe failed the quiz screen only when the first question drawn was a log
  question, which is why #114's a11y job failed while main passed. The box now
  keeps its terminal colours (`.log-terminal` in `index.css`).
- **The flashcard tip matches the buttons.** It still said "mark it mastered",
  which predates Knew it / Again.

## Verification

- Production build at 360, 390, 640 and 700px: the nav is 78px at each width,
  the active section stays inside the row (including Ideas, the last one), and
  the page never scrolls sideways. Screenshots inspected at 390px in both
  themes.
- axe on the quiz screen with the format set to log questions: before the fix,
  light mode fails on the same two elements CI reported; after, both themes are
  clean.
- `scripts/a11y.mjs`: 50 screens, no violations. axe at 390px on Home,
  Flashcards and Ideas in both themes: no violations.
- `npm run lint`, `npx vitest run` (61 files, 515 tests), `npm run build`, and `scripts/check-release.mjs` against the parent branch and `origin/main` all pass locally. CI's container job runs on the PR; no local Docker here.
- Not verified on a physical phone. Rows that scroll sideways are less
  discoverable than a grid, which is the trade-off this makes; the partly
  visible fifth tile is the cue.

## Deploy impact

Client-only. No server, schema, Compose or image change.
