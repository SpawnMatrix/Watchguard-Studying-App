# Version 1.29.0 — Download questions for your track

The browser loads one question bank per learning track. Vite partitions the
canonical revised catalogue at build time, so there is no duplicate authored
source to maintain. The server and existing content tests retain the full bank.

A small ID/track/topic index supports readiness and history across tracks.
Question sections wait for their selected track before mounting. Saved sessions
load their original track before resuming; weakness review additionally loads
tracks named by missed IDs. New-session actions await their bank and preserve
the current session on failure. Loaded tracks are cached and deduplicated.
An explicit All-tracks saved session still loads all tracks.

Q&A uses the same partition while preserving its original authored-question
subset. IDs, questions, answers, explanations, twin groups and counts are
unchanged. No new storage key. Content parity is tested against the full bank.

## Verification and sizes

Before: catalog + authoredQuestions = 514.72 kB raw / 157.11 kB gzip,
downloaded together for every question track. After (bank plus shared loader,
ID index and scenario generators, excluding unchanged section/UI chunks):

| Track | Bank raw / gzip kB | Total raw / gzip kB | Gzip saving |
| --- | --- | --- | --- |
| Local Firebox | 394.25 / 101.46 | 501.13 / 128.27 | 18.4% |
| Network+ | 136.44 / 38.74 | 243.32 / 65.55 | 58.3% |
| Cloud | 41.76 / 11.74 | 148.64 / 38.55 | 75.5% |

Shared code is 106.88 / 26.81 kB; scenario generators remain shared code, but
only the selected track is materialized. Generated seed examples are not sent
again in the authored bank. Repeated strings, citations and diagrams are pooled
within each chunk. All three tracks together cost more than before (679.33 /
178.75 kB); that is the explicit tradeoff for independent single-track downloads.
Entry changes from 246.07 / 78.44 to 246.39 / 78.55 kB; no bank in first load.
Practice counts now describe the current question pool, not every cached track.
