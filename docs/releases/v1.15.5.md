# Version 1.15.5 — Drop the unused zustand dependency

Version 1.15.3 deleted `src/store/useStudyStore.ts`, the only file that imported `zustand`, and deliberately left the package in place so that release stayed deletions-only. This release removes it.

- `zustand` is gone from `dependencies` in `package.json` and from `package-lock.json`. No other package changed: `zustand` had no dependencies of its own, and none of its optional peers (`immer`, `use-sync-external-store`) were installed for it.
- Nothing in `src`, `server.ts`, `server/` or `scripts` imports it, so the client bundle and `dist/server.cjs` are unchanged in behaviour. The production image installs one package fewer.

No migration, no data-contract, Compose or deploy-script change. The branch is delivered by pull request and does not deploy itself.
